# Досудебка

Самостоятельное React/Vite-приложение для подготовки индивидуальных и коллективных досудебных претензий.

На текущем этапе пользователь, документы, коллективные комнаты, участники, тариф юриста, заявки CHECK и счётчик раннего доступа хранятся локально в браузере через `localStorage`. Внешний backend и база данных не используются.

## Команды

- `npm run dev` — локальная разработка.
- `npm run build` — production-сборка.
- `npm run lint` — проверка исходников.
