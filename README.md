# ДокМаркет

Маркетплейс цифровых документов и услуг специалистов.

Покупатель может искать и сравнивать документы, добавлять их в избранное и корзину, оформлять заказы, получать доступ к покупкам, заказывать услуги специалистов и оставлять отзывы после завершённых заказов.

Продавец может создать профиль, размещать документы и услуги, отправлять их на модерацию, получать заказы и вести работу с покупателем внутри приложения.

«Досудебка» работает как один из встроенных сервисов ДокМаркета, а не как отдельный главный продукт.

## Стек

- React + Vite
- Supabase: авторизация, база данных, Storage, Edge Functions
- Vercel: web-деплой

## Основные команды

- `npm run dev` — локальная разработка
- `npm run build` — production-сборка
- `npm run lint` — проверка исходников
- `npm run agents -- --task "Описание задачи"` — трёхагентная проверка крупной задачи

## Статус

Основные сценарии маркетплейса реализуются в `main`. Платёжный провайдер подключается отдельным этапом.
